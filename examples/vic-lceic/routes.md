# routes.md — route review

One row per finding. `current route` is what `claims-machine.txt` declares today; the last column is
for a person to fill by hand — **do not guess it**. Mark which of the three the finding actually is:

- **witness said** — it compresses testimony/submissions; check against the corpus (route `source`).
- **committee concluded** — a Committee value judgment or call to act (route `evaluative`).
- **fact about world** — a factual claim needing an external truth-maker (route `evidence`).

A `data-gap` finding (a claim about a dataset's own limits) is a fourth kind; note it in the column
if that is what a row is. When the filled column disagrees with `current route`, that route is the
one to fix in `claims-machine.txt` before the next full run.
