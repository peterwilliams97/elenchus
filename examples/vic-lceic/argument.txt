# argument.txt — the LCEIC report as an argument tree (spec/ARGUMENT.md)
#
# The report as a root proposition refined down to evidence:
#   root → recommendation (R1–R11) → finding (F1–F55) → atomic claim (ids in claims-machine.txt).
# This file carries CONTENT and STRUCTURE only. Judgements are DERIVED, never authored, so there is
# no judgement here — they do not exist until a merged chain (spec/TREE.md) is pooled onto the leaves
# and propagated up. A judgement column in this file would be a fabricated result.
#
# Line format (indentation = depth; a child sits one level below its parent):
#   <id>[ ?]  | <content, the report's words, short>  | <edge / provenance note>
# A bare id at claim depth (level 3) is an ATOMIC-CLAIM LEAF — its text, route, and source live in
# claims-machine.txt; not repeated here, to keep one source of truth for claim text.
#
# Edge markers (spec/ARGUMENT.md § Edges):
#   (default)  load-bearing, report-stated — the parent's content directly acts on / remedies /
#              decomposes to the child.
#   ?          the report does NOT establish this edge: it co-locates parent and child, or the child
#              plausibly bears on the parent, but the report never says the parent rests on it. A
#              question for a human, not a guess. Candidate children are named in the note, uncommitted.
#   [opinion]  the finding (or a sub-claim) is a Committee value judgement (route=evaluative) — never
#              judged; contributes nothing to a parent's hold/fail. See claims-machine.txt.
#
# Attachment provenance: the report's "Findings and recommendations" section, printed pp. xi–xvii,
# which prints findings and recommendations in order with their subsection (§) page anchors. Each
# recommendation's solid child is the finding in its own subsection whose subject it acts on.
#
# `base` realises the descriptive base — every finding no recommendation rests on — as one root child
# on a ? edge (the report routes these to no recommendation and does not state they establish the
# root). It keeps all 55 findings in the tree; nothing is dropped.
#
# Root is SYNTHESISED: the report states no single thesis sentence. Verbatim anchor — Chair's
# foreword, printed p-ix: "the economic and social impact of the cultural and creative industries …
# on the lives of Victorians". The rest of the root's content compresses the 11 recommendations'
# shared ask.
