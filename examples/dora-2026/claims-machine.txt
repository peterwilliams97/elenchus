# claims-machine.txt — atomic claims decomposed from the DORA "State of AI-assisted Software
# Development" report (Google Cloud / DORA, v.2025.2, 142 pp., CC BY-NC-SA 4.0). Report →
# argument-tree corpus; the argument side is argument.txt.
#
# This is the CLAIM side of the assay. The only held SOURCE is report.pdf itself (sources/MANIFEST.md),
# so the only automated check this corpus enables is INTERNAL CONSISTENCY: does the report actually
# state the claim at its `ref` page, and do figures restated across pages/chapters agree. It does NOT
# ground the survey figures — their truth-maker is the study microdata (4,867 responses), which is not
# held, so every route=survey claim grounds to `unverifiable` by design (sources/MANIFEST.md "Not held").
#
# Line format (pipe-delimited, 5 fields):
#   <id> | route=<r> | ref=§<section heading> p<printed-page> | <claim> | src=<locator + note>
#
# route= (what could settle the claim; see CLAUDE.md axis boundary):
#   survey     — a statistic FROM the 2025 DORA study: a raw percentage/median, OR a modeled
#                comparison (the "estimated effect", "with a high degree of certainty ... amplified"
#                capability findings, which are Bayesian regression results over the same microdata).
#                Truth-maker = survey microdata + the fitted models (NOT HELD → grounding unverifiable).
#                report.pdf settles only internal consistency. This is the corpus's dominant class.
#   evidence   — a non-survey factual world-claim: a figure cited from ANOTHER report (Stack Overflow,
#                Atlassian, McKinsey, LinkedIn, Stanford HAI, METR, the 2024 DORA Report), a
#                methodology/apparatus fact, a named case-study result, or a figure-reading. Truth-maker
#                external — almost always a not-held third-party document or prior edition; report.pdf
#                settles internal consistency only.
#   evaluative — DORA interpretation / value judgement ("AI is an amplifier", "the speed vs. stability
#                trade-off is a myth", "excellence is achievable", the seven-capabilities advice
#                imperatives). Not truth-apt; checkable only as "did the report say it", never grounded.
#                Not judged.
#   data-gap   — a claim about the report's own scope / measurement limits (snapshot-not-video, the
#                "comparisons not effects" caveat, survey conditionality).
#
# src= names the held locator (report.pdf + printed page) and, where the real truth-maker is not held,
# names it so a grounding run's `unverifiable` is legible. `restates <id>` marks a deliberate
# cross-page/cross-chapter duplicate: the pair is an internal-consistency check, not an accident — the
# figures must agree. § headings are the report's own (bold) headings; printed page = footer number
# (printed page == PDF page here, so report_page_offset = 0, sources/MANIFEST.md).
