# claims-machine.txt — atomic claims decomposed from the Quocirca Print Security Landscape 2026
# (RICOH excerpt, July 2026). Report → argument-tree corpus; the argument side is argument.txt.
#
# This is the CLAIM side of the assay. The only held SOURCE is report.pdf itself (sources/MANIFEST.md),
# so the only automated check this corpus enables is INTERNAL CONSISTENCY: does the report actually
# state the claim at its `ref` page, and do figures restated across pages agree. It does NOT ground
# the survey figures — their truth-maker is the study microdata, which is not held, so every
# `route=survey` claim grounds to `unverifiable` by design (sources/MANIFEST.md "Not held").
#
# Line format (pipe-delimited, 5 fields):
#   <id> | route=<r> | ref=§<section heading> p<printed-page> | <claim> | src=<locator + note>
#
# route= (what could settle the claim; see CLAUDE.md axis boundary):
#   survey     — a statistic FROM the 2026 study. Truth-maker = survey microdata (NOT HELD →
#                grounding unverifiable). report.pdf settles only internal consistency (is the number
#                printed here; do restatements agree). This is the corpus's dominant class.
#   evidence   — a non-survey factual world-claim (an acquisition, a product/standard capability, a
#                firm-history fact, a figure-reading). Truth-maker external, mostly a not-held vendor
#                briefing or prior edition; report.pdf settles internal consistency only.
#   evaluative — Quocirca opinion / value judgement ("under-prioritised", "stands out", "foundational").
#                Not truth-apt; checkable only as "did the report say it", never grounded. Not judged.
#   data-gap   — a claim about the report's own numeric limits (the rounding caveat).
#
# src= names the held locator (report.pdf + printed page) and, where the real truth-maker is not held,
# names it so a grounding run's `unverifiable` is legible. `restates <id>` marks a deliberate
# cross-page duplicate: the pair is an internal-consistency check, not an accident — the figures must
# agree. § headings are the report's own (unnumbered) bold headings; printed page = footer number.
