# DEFECT — reference-class gaming (target axis: **Base rate / magnitude**)

> Openly-constructed adversarial probe. The construction *is* the ground truth. See `../README.md`.

## The engineered defect

**Reference-class gaming.** A real number (19% net) is compared against a *flattering, gerrymandered*
reference class ("venture funds of its vintage") while the natural benchmark is silently dropped. For
a year in which a broad equity index returned more than 19%, "real outperformance" is false against
the comparison an LP would actually use — but true against the hand-picked class of same-vintage VC
funds. The magnitude is genuine; the **base of comparison is rigged**.

This targets the Base-rate / magnitude axis: *"is there a real quantity and a comparison, or just a
direction?"* The probe asks a sharper question than the axis was written for — see the honest note
below.

## Axes it is deliberately clean on

- **Equivocation** — terms are stable; "return," "net," "outperformance" don't shift meaning.
- **Falsifiability** — every figure (19%, top-quartile, index return) is checkable; not vacuous.
- **Causality vs correlation** — no causal mechanism is asserted.
- **Evidence** — a concrete quantity is given, not bare assertion.

## Most likely *adjacent* catch

- **Hidden premise** — the load-bearing unstated premise is "beating same-vintage VC peers ⇒ beating
  the market." A hidden-premise finding is the same defect seen from another axis and counts as the
  probe working.

## Honest design note — this is a borderline probe by construction

The Base-rate axis as written rewards the *presence* of a quantity and a comparison. This claim has
**both** on its surface — a number *and* a named comparison class. The defect is subtler: the
comparison class is *gamed*, not missing. So this probe genuinely tests whether the axis catches a
**misleading** base rate or only an **absent** one. Expect more `substantive` / `partial` leakage
here than on the other five probes. **A miss is partly a mapped envelope limit, not purely a critic
error** — record it as such. The probe earns its keep either way: a catch shows the axis reaches
reference-class gaming; a miss draws the line where it stops.

## How this probe was constructed

Took a true, unremarkable number and wrapped it in the single most flattering true reference class,
then stated the misleading comparative ("real outperformance") that the gamed class licenses but the
honest benchmark does not. No other defect was added, to isolate the base-rate signal.
