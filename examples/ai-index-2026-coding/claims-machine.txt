# claims-machine.txt — atomic claims decomposed from the AI Index 2026 coding section
# (Stanford HAI, AI Index Report 2026, Ch.2 Technical Performance, §2.5 "Software", printed pp100–102).
# Report → argument-tree corpus; the argument side is argument.txt.
#
# This is the CLAIM side of the assay. Held SOURCES are report.pdf itself and seven Wayback captures
# of the three benchmark leaderboards (sources/MANIFEST.md "Leaderboard captures"). Two checks follow:
# INTERNAL CONSISTENCY against report.pdf (does the section state the claim at its `ref` page; do the
# prose figures agree with the figure they restate), and GROUNDING a route=benchmark score against a
# held capture — which grounds the leaderboard's state at the CAPTURE timestamp, bracketing the
# report's "as of February 2026" / "early 2026" snapshot rather than reproducing it. So a benchmark
# claim grounds where a capture carries its value (e.g. SWE-bench 76.80, Terminal-Bench 77.3%, Vibe
# Code Bench 57.57%) and stays unverifiable where the report's snapshot falls between captures (the
# Vibe Code Bench v1.1 leader ordering — sources/MANIFEST.md "capture gap").
#
# Line format (pipe-delimited, 5 fields):
#   <id> | route=<r> | ref=§<section heading> p<printed-page> | <claim> | src=<locator + note>
#
# route= (what could settle the claim; see CLAUDE.md axis boundary):
#   benchmark  — a score/result FROM a benchmark leaderboard. Truth-maker = the leaderboard state the
#                report read (as of Feb 2026 / early 2026), now HELD as Wayback captures that bracket
#                that date (sources/MANIFEST.md). report.pdf still settles internal consistency (is the
#                number printed here; does the prose agree with its figure). This is the corpus's
#                dominant class.
#   evidence   — a non-score factual world-claim (a benchmark's definition, a novelty claim, a
#                figure-reading). Truth-maker external, not held; report.pdf settles internal
#                consistency only.
#   evaluative — an AI Index interpretive judgement ("attention has shifted", "significantly improved",
#                "remains a difficult task"). Not truth-apt; checkable only as "did the section say
#                it", never grounded. Not judged.
#   data-gap   — a claim about the section's own dating / measurement limits.
#
# src= names the held locator (report.pdf + printed page) and the real truth-maker — for benchmark
# claims, the leaderboard capture that carries it (leaderboards/…) or, where none does, why it stays
# `unverifiable`. An `INTERNAL:` note flags where the prose
# figure and the figure it restates appear to disagree — the internal-consistency check a judge run
# against report.pdf is meant to catch. § headings are the report's own; printed page = footer number.
